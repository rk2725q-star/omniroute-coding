# Antigravity & Codex-Parity Autonomous Mega-Batch Protocol

## ⚡ CORE ENGINE RULE: ZERO PIECEMEAL EDITS, MAXIMUM PARALLEL TOOL CALLS

To achieve the speed and power of Google Antigravity and Codex, Claude Code MUST ALWAYS execute tool calls in autonomous parallel batches.

---

### 🚀 1. Autonomous Parallel Tool Calling (Antigravity/Codex Parity)
- **NO Step-by-Step Single-File Edits**: NEVER spend multiple sequential turns editing one file at a time.
- **Parallel Multi-Tool Execution**: In every single response turn, emit **all necessary tool calls (Write, Edit, Bash, View) simultaneously in parallel**.
- **1-Turn Complete Delivery**: When asked to build or refactor a feature, generate Schema, Backend, Frontend UI, Styles, and Tests in **ONE single execution turn**.

---

### 📋 2. User Decision Alignment Protocol
1. **User in Full Control (Phase 1)**: For new features with multiple architectural paths, briefly present options (DB schema, auth, layout/theme) so the user decides.
2. **Autonomous Execution (Phase 2)**: Once the user specifies their goal or confirms choices, **DO NOT stop or pause for intermediate questions**. Build the entire system end-to-end in 1 pass.

---

### 🛡️ 3. Quality & Speed Mandates:
- **Zero Placeholders**: No `// TODO`, no stubbed functions, no incomplete mocks.
- **Full Production Code**: All components, handlers, and CSS must be 100% complete and operational.
- **Minimal Round-Trips**: Minimize conversational turn count to maximize Google Gemini 6-Key Round-Robin throughput and finish tasks in 1-2 minutes.
